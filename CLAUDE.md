See [AGENTS.md](./AGENTS.md) for project structure, conventions, and the required
workflow for every change (add tests and make them pass, update the release notes, and
bump the version on Android and iOS).

## Commits

Never commit, and never offer to commit. Leave the working tree prepared (tests green,
release notes and versions updated) and finish by suggesting a commit message. The user
reviews the changes manually and makes the commit themselves.
